# Repository working notes

## Presentation convention

Current READMEs, reports, dashboards and review documents describe the implementation,
methods, observed results and limitations without developer or creator bylines.
Apply the same wording and evidence boundaries to the matching Drive review files.
Retain third-party credits, source citations, frozen test results, checkpoint decisions
and original provenance records. A presentation edit must not become a claim that
historical verification was rerun or that an unresolved result was fixed.
